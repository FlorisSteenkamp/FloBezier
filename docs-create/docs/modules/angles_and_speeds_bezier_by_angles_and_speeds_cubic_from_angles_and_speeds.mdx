```typescript
function cubicFromAnglesAndSpeeds(anglesAndSpeeds: AnglesAndSpeeds): number[][]
```

*Defined in [angles-and-speeds/bezier-by-angles-and-speeds/cubic-from-angles-and-speeds.ts:23](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/angles-and-speeds/bezier-by-angles-and-speeds/cubic-from-angles-and-speeds.ts#L23)*

Returns a cubic bezier curve (given by its control points) with the given
angles-and-speeds parameters.

#### Parameters:

Name | Type | Description |
------ | ------ | ------ |
`anglesAndSpeeds` | AnglesAndSpeeds | the angles-and-speeds parameters, i.e. an object with the following properties: * `α`   -&gt; initial tangent angle in radians * `β`   -&gt; terminal tangent angle in radians * `s0`  -&gt; initial speed * `s1`  -&gt; terminal speed * `L`   -&gt; distance between initial and final point (cannot be 0) * `rot` -&gt; rotation of entire curve * `p`   -&gt; initial position offset |
