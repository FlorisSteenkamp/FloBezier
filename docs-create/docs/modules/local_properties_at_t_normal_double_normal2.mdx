```typescript
function normal2(ps: number[][], t: number): number[]
```

*Defined in [local-properties-at-t/normal/double/normal2.ts:23](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/local-properties-at-t/normal/double/normal2.ts#L23)*

Returns a normal vector (not necessarily of unit length) of a bezier curve
at a specific given parameter value `t` by simply taking the `tangent` at
that point and rotating it by 90 degrees.

* uses double precision calculations internally
* unlike [normal](local_properties_at_t_normal_double_normal.mdx), if the tangent vanishes at `t` (e.g. at a cusp or
where control points coincide) a normal is still returned (based on the
direction the curve leaves the point in; or arrives at the point in if
`t === 1`); only if all control points coincide is `[0,0]` returned

#### Parameters:

Name | Type | Description |
------ | ------ | ------ |
`ps` | number[][] | a linear, quadratic or cubic bezier curve given by its ordered control points, e.g. `[[0,0],[1,1],[2,1],[2,0]]` |
`t` | number | the parameter value where the normal should be evaluated |
