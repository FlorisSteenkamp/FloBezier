function ddGetCoeffsXFromY_WithRunningErr(ps: number[][], y: number): { coeffs: number[][]; errorBound: number[]; } | undefined

*Defined in [x-from-y/double-double/dd-get-coeffs-x-from-y-with-running-err.ts:23](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/x-from-y/double-double/dd-get-coeffs-x-from-y-with-running-err.ts#L23)*

Returns a polynomial (and a coefficientwise error bound) whose roots are
the `x` coordinates given the `y` coordinate of the given bezier curve.

* this is calculated by swapping the `x` and `y` coordinates of the bezier
(i.e. reflecting it in the line `y = x`) and getting the polynomial whose
roots are the `y` coordinates given the `x` coordinate (which is the given
`y`) of the reflected curve

* **precondition**: the given curve must really be of its stated order (e.g. use [reduceOrderIfPossible](transformation_reduce_order_if_possible.mdx) first); for a degenerate curve (e.g. a cubic that is really a quadratic) all returned coefficients are zero (or, due to round-off, very nearly zero); use [eGetCoeffsXFromY](x_from_y_expansion_get_coeffs_x_from_y.mdx) instead which correctly handles degenerate curves; the returned error bound remains valid though, so that certified algorithms relying on it will correctly fall back to exact arithmetic

#### Parameters:

Name | Type | Description |
------ | ------ | ------ |
`ps` | number[][] | an order 1, 2 or 3 bezier curve |
`y` | number | the `y` coordinate |
