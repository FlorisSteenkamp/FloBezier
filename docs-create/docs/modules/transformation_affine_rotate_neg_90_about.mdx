*Defined in [transformation/affine/rotate-neg-90-about.ts:15](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/transformation/affine/rotate-neg-90-about.ts#L15)*

Returns the given bezier curve rotated anti-clockwise about the given point
by exactly -90 degrees (i.e. clockwise by 90 degrees).

This is an exact special case of [rotateAbout](transformation_affine_rotate_about.mdx) that avoids the floating
point error introduced by evaluating `sin`/`cos` of a rounded `Math.PI/2`.
The rotation reduces to `(x,y) -> (y,-x)` (about the origin) which is exact.
