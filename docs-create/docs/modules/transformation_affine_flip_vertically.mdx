*Defined in [transformation/affine/flip-vertically.ts:13](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/transformation/affine/flip-vertically.ts#L13)*

Returns the given bezier curve flipped vertically (mirrored top-to-bottom) about the x-axis, i.e. each control point `[x,y]` is mapped to `[x,-y]`.
