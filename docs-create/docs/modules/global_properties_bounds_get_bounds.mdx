```typescript
function getBounds(ps: number[][]): object
```

*Defined in [global-properties/bounds/get-bounds.ts:21](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/global-properties/bounds/get-bounds.ts#L21)*

Returns an axis-aligned bounding box together with the `t` values where the
bounds on the bezier are reached in the form:
```
{
     ts: [[tMinX, tMinY], [tMaxX, tMaxY]];
     box: [[minX,  minY], [maxX,  maxY ]];
}
```
