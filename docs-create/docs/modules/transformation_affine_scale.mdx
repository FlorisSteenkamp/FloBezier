```typescript
function scale(ps: number[][], s: number): number[][]
```

*Defined in [transformation/affine/scale.ts:17](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/transformation/affine/scale.ts#L17)*

Returns the given bezier curve scaled about the origin by the given factor.

* to scale about another point, first `translate` the curve, scale, then translate back
* uses double precision calculations internally
