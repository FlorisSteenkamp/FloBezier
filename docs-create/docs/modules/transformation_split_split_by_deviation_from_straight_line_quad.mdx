function splitByDeviationFromStraightLine_Quad(ps: number[][], maxD: number): number[]

*Defined in [transformation/split/split-by-deviation-from-straight-line-quad.ts:18](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/transformation/split/split-by-deviation-from-straight-line-quad.ts#L18)*

Split the given quadratic bezier curve into pieces (given as an array of 
parameter `t` values) such that each piece is guaranteed to deviate less
than `maxD` from a straight line.

#### Parameters:

Name | Type | Description |
------ | ------ | ------ |
`ps` | number[][] | an order 2 bezier curve given as an ordered array of its control point coordinates, e.g. `[[0,0], [1,1], [2,1]]` |
`maxD` | number | the maximum allowed deviation of each piece from a straight line |
