function toCubic(ps: number[][]): number[][]

*Defined in [transformation/degree-or-type/to-cubic.ts:18](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/transformation/degree-or-type/to-cubic.ts#L18)*

Returns a cubic bezier curve that is equivalent to the given linear or
quadratic bezier curve.
Cubics are just returned unaltered.

This function simply uses `lineToCubic` or `quadraticToCubic` internally.
