*Defined in [transformation/affine/rotate-90.ts:14](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/transformation/affine/rotate-90.ts#L14)*

Returns the given bezier curve rotated anti-clockwise about the origin by
exactly 90 degrees.

This is an exact special case of [rotate](transformation_affine_rotate.mdx) that avoids the floating point
error introduced by evaluating `sin`/`cos` of a rounded `Math.PI/2`. The
rotation reduces to `(x,y) -> (-y,x)` which is exact.
