function generateSelfIntersecting(p0: number[], p1: number[], p2: number[], ts: number[]): number[][]

*Defined in [create/generate-self-intersecting.ts:15](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/create/generate-self-intersecting.ts#L15)*

Returns the cubic bezier curve with given starting, 2nd and 3rd control
points such that there is a self-intersection.
* **in-exact:** the result may not be exact due to floating point round-off
