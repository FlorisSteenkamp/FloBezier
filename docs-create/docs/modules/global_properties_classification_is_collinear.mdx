```typescript
function isCollinear(ps: number[][]): boolean
```

*Defined in [global-properties/classification/is-collinear.ts:19](https://github.com/FlorisSteenkamp/FloBezier/blob/master/src/global-properties/classification/is-collinear.ts#L19)*

Returns `true` if the given bezier curve has all control points collinear,
`false` otherwise.
* if you need to know whether a given bezier curve can be converted to an
order 1 bezier curve (a line) such that the same `(x,y)` point is returned
for the same `t` value then use e.g. [isQuadReallyLine](global_properties_classification_is_quad_really_line.mdx) instead.

* **exact** not susceptible to floating point round-off
